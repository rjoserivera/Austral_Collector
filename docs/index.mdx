## ¿Qué es Austral Collector?

**Austral Collector** es una plataforma web comunitaria para coleccionistas chilenos de figuras, juguetes vintage y objetos de colección. Diseñada con una estética **Dark-Fantasy y Steampunk**, ofrece animaciones fluidas, carruseles interactivos, modales dinámicos y diseño completamente adaptable a dispositivos móviles.

La plataforma permite a los miembros registrados publicar sus colecciones, votar figuras, interactuar con la comunidad y acceder a un panel de administración completo con gestión de usuarios, eventos, galería, promociones, moderación de contenido y más.

## Stack Tecnológico

| Capa | Tecnología |
|---|---|
| Frontend | React 19 + Vite 8 |
| Estilos | Vanilla CSS (Dark-Fantasy / Steampunk theme) |
| Routing | React Router DOM v7 |
| Backend | PHP 8 + PDO |
| Base de datos | MySQL |
| Autenticación | JWT (JSON Web Tokens) + roles |
| PWA | vite-plugin-pwa + Workbox |
| Offline | IndexedDB (idb) |
| Notificaciones | Sistema Toast + Confirm custom (sin librerías externas) |
| Mascota Virtual | VirtualAssistant con mensajes por página y comportamiento por inactividad |

## Características Destacadas

- 🎨 **Diseño Dark-Fantasy / Steampunk** con tipografías variables y paleta dorada
- 🖼️ **Galería de figuras** con votos, comentarios y perfiles públicos de coleccionistas
- 📰 **Dashboard de usuario** con publicaciones, likes, reordenamiento y actividad
- 🛡️ **Panel Admin completo** — usuarios, eventos, galería, portafolio, promociones, videos, moderación, log de actividad
- 🤖 **Mascota Virtual** (VirtualAssistant) con mensajes contextuales por página y aparición automática al detectar inactividad en móvil
- 📱 **PWA** instalable, con soporte offline vía IndexedDB y sincronización automática
- 🔒 **Autenticación JWT** con roles (`admin` / `member`), clave temporal y cambio forzado de contraseña
- 📧 **Sistema de correos** para claves temporales, advertencias y formulario de contacto
- 🏆 **Sistema de Destacados** — miembro destacado, cumpleañero del mes y mensajes personalizados
- ✅ **Badge de Verificación** para miembros verificados por el administrador
- ⭐ **Sistema de valoración de perfiles** — los miembros pueden puntuar los perfiles de otros coleccionistas
- 🔔 **Sistema de notificaciones Toast** y diálogos de confirmación personalizados
