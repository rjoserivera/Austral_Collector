## ¿Qué es Austral Collector?

**Austral Collector** es una plataforma web comunitaria para coleccionistas chilenos de figuras antiguas, juguetes vintage y objetos de colección. Está diseñada con una estética **Dark-Fantasy y Steampunk**, con animaciones fluidas, carruseles infinitos, modales interactivos y diseño completamente adaptable a dispositivos móviles.

La plataforma permite a los miembros registrados publicar sus colecciones, votar figuras, interactuar con la comunidad y acceder a un panel de administración completo.

## Stack Tecnológico

| Capa | Tecnología |
|---|---|
| Frontend | React 19 + Vite 8 |
| Estilos | Vanilla CSS (Dark-Fantasy theme) |
| Routing | React Router DOM v7 |
| Backend | PHP 8 + PDO |
| Base de datos | MySQL (via XAMPP) |
| Autenticación | JWT (JSON Web Tokens) |
| PWA | vite-plugin-pwa |
| Offline | IndexedDB (idb) |

## Características Destacadas

- 🎨 **Diseño Dark-Fantasy / Steampunk** con tipografías variables y paleta dorada
- 🖼️ **Galería de figuras** con votos, comentarios y perfiles públicos de coleccionistas
- 📰 **Dashboard de usuario** con publicaciones, likes y actividad
- 🛡️ **Panel Admin completo** con control de usuarios, eventos, galería y portafolio
- 📱 **PWA** instalable, con soporte offline vía IndexedDB
- 🔒 **Autenticación JWT** con roles (admin / miembro)
- 📧 **Sistema de correos** para clave temporal y contacto
