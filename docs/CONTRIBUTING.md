# Contribuir a la Documentación

¡Gracias por tu interés en contribuir a la documentación de **Austral Collector**! Esta guía te ayudará a comenzar.

---

## ¿Cómo contribuir?

### Opción 1: Editar directamente en GitHub

1. Ve a la página que deseas editar
2. Haz clic en el botón **"Editar este archivo"** (el ícono de lápiz)
3. Realiza tus cambios y envía un pull request

### Opción 2: Desarrollo local

1. Haz un fork y clona este repositorio
2. Instala el CLI de Mintlify: `npm i -g mintlify`
3. Crea una rama para tus cambios
4. Realiza los cambios necesarios
5. Navega a la carpeta `docs/` y ejecuta `mintlify dev`
6. Previsualiza los cambios en `http://localhost:3000`
7. Haz commit de tus cambios y envía un pull request

---

## Tipos de contribuciones bienvenidas

- 📝 Corrección de errores ortográficos o gramaticales
- 📖 Mejora de explicaciones existentes
- ➕ Documentación de nuevas funcionalidades
- 🌐 Traducciones o mejoras al español
- 💡 Ejemplos de uso o casos prácticos

---

## Guía de escritura

- **Usa voz activa:** "Ejecuta el comando" en lugar de "El comando debe ser ejecutado"
- **Dirígete al lector directamente:** Usa "tú" en lugar de "el usuario"
- **Sé conciso:** Una idea por oración
- **Empieza con el objetivo:** Comienza las instrucciones con lo que el usuario quiere lograr
- **Sé consistente con la terminología:** No alternar entre sinónimos para el mismo concepto
- **Incluye ejemplos:** Muestra, no solo expliques
- **Escribe en español:** Toda la documentación está en español

---

## Código de Conducta

Pedimos a todos los colaboradores que mantengan un ambiente respetuoso y constructivo. Las contribuciones deben estar alineadas con el espíritu de la comunidad **Austral Collector**: apasionada por el coleccionismo y el buen trato entre sus miembros.
